# Android mockups — dark review, batch 3 (A21c–A29b)

Reviewed against `docs/design/android-screens.md` (frame lists), `STYLE.md`, and
`screens.md` (Visual direction, the fleet). Image-generation text artefacts ignored unless they
change meaning.

**Fixes that apply to every frame marked FIX below (add them to every regenerated prompt):**
- Status row clock reads **09:41**, not 10:24.
- Use **no generic "YAAC" Material app bar**: no hamburger, no app-wide search icon, no "YAAC"
  title. A thread's side-pane tab (Files, file, diff, Terminal, Browser) sits under the **thread
  top bar**: ← · state mark + thread title, with tag/breadcrumb on line two · the red `! 2`
  Needs-you button · the command mark · ⋮; then the tab row (Chat first, then the side-pane tabs, ＋).
  Settings pages use ← · "Settings › <page>" only.
- No Material blue anywhere: toggles, radios, links, selected tabs, the selected dropdown item
  and primary buttons are neutral (primary button = solid #E6E8EC with a #16181D label; switches
  in the neutral primary-text colour).
- Inputs, dropdowns, code/key boxes and secondary buttons have a **faint fill (#1E2128), no
  outline**. Only the focused one gets the neutral #C9CED6 focus ring. Secondary buttons are
  plain text without a fill. No hairline dividers between list rows. Separate the sections with
  space and small headings.
- A running thread's header mark is the **primary-text play triangle**, not a hollow circle or spinner.
